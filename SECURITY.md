# Security Policy

## Supported Versions

| Component | Supported Targets | Status |
|---|---|---|
| EOL-PHP-SecAuto CLI | 1.x.x | ✅ Supported |
| GitHub Action (`action.yml`) | v1 | ✅ Supported |
| Backported C-Patches | PHP 5.4 – 8.1 (Debian & Alpine) | ✅ Supported |

## Vulnerability Reporting

If you identify a security defect or patch bypass in EOL-PHP-SecAuto:
* Do not submit public issues.
* Submit a confidential advisory via GitHub Security Advisories or contact Anton Barinov.
